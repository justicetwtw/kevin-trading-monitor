# 系統架構

## 評分公式

```
推播分數 = 底層系統評分(0-100,經權重縮放)
        + Layer 0 Modifier(-30 ~ +20)
        + Layer 0+ 警示標籤(informational)
        × 否決乘數(觸發任一 = ×0)

評級:
  ≥ 70 → 🟢 推播
  50-69 → 🟡 日報
  < 50 → ⚪ 不通知
```

## 三層篩選器

1. **濾波 1**:評分閾值(≥70)
2. **濾波 2**:標的優先級(P0/P1/P2/P3)
3. **濾波 3**:推播頻率上限(P0 ≤5/日,P1 ≤10/日)
