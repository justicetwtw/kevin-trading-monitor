# Kevin 的選擇權哲學

> brief / 訊號 / 系統呈現的「視角源頭」。
> 任何新增 brief 段落、訊號描述、訊息文案都必須符合本檔的視角。

## 核心定位

我不是 short premium trader,是 **long-term investor 用選擇權優化買賣執行**。
所有訊號 / brief / 系統呈現都該以投資者視角而非 trader 視角設計。

具體差別:
- ❌ trader 視角:「IVR 65 + delta 0.20,風報比 1:3,可進場」
- ✅ investor 視角:「NVDA 跌到我的接貨區了,賣 PUT 等於打折買單,履約我願意接」

## Sell PUT = 打折買單

- 在我**願意接的價格**設單
- 收 premium = 等待費(就算沒履約,也賺到等待時間的錢)
- 履約 = 用便宜價買到優質股 + 收 premium = bonus
- 沒履約 = 收 premium 等下次機會

### 判斷時機(三條件齊備才高勝率)

| 條件 | 標準 | 失敗的意義 |
|---|---|---|
| 標的是白名單優質股 | `SELL_PUT_WHITELIST` | 履約後不願長期持有 → 永遠不該賣 |
| 股價跌到接貨區 | 距 52W 高 ≤ -15% | 太貴,履約價沒便宜 |
| RSI 過低 | RSI(14) < 35 | 還沒超賣,等下跌 |
| IVR 高(加分項) | IVR ≥ 60(VIX ≥ 25) | 賣方溢價薄,等待費少 |

> 三條件齊備 = 訊號等級「綠燈」(直接行動)
> 兩條件齊備 = 「黃燈」(觀察,等第三條件)
> 一條件齊備 = 「白燈」(只列為候選,不行動)

## Sell CALL = 鎖利出場單

- 必須**有持倉**,在我**願意賣的價格**設單
- 收 premium = 等待費
- 履約 = 在好價格獲利出場 + 收 premium = bonus
- 沒履約 = 收 premium 繼續持有看更高

### 判斷時機(三條件齊備才高勝率)

| 條件 | 標準 | 失敗的意義 |
|---|---|---|
| 標的是現有持倉 | LEAPS / 現股 在 positions.json | 沒倉怎麼賣 call |
| 股價漲到出場區 | 距 52W 高 ≥ -3% | 還沒到願賣價,別鎖死上漲空間 |
| RSI 過熱 | RSI(14) > 70 | 還沒超買,可能繼續漲 |
| 持倉已獲利 | LEAPS pnl ≥ +50%(過保護點) | 還在虧 / 微利,鎖利沒意義 |

## LEAPS 進場 = 深度便宜買單

- 不是抓底,是**白菜價買優質股**
- DTE ≥ 12 個月(走長線,不被短期波動趕出場)

### 判斷時機(三條件齊備才行動)

| 條件 | 標準 | 失敗的意義 |
|---|---|---|
| 標的是白名單優質股 | `SELL_PUT_WHITELIST`(同名單) | 不是核心持倉名單,不該下重注 |
| 股價深度回檔 | 距 52W 高 ≤ -25% | 還沒到白菜價 |
| RSI 過低 | RSI(14) < 30 | 還在超賣前緣,等止跌 |
| VIX sweet spot | 20 ≤ VIX ≤ 30 | 太低 → 沒恐慌價;太高 → 還沒止跌 |
| IVR 健康區 | 30 ≤ IVR ≤ 70 | 太低 → IV 還會漲(權利金會貴);太高 → 已恐慌頂部 |

## 市場環境分級(VIX 視角)

| VIX | 環境 | 賣方行動 |
|---|---|---|
| < 15 | 極低波動 | 賣方無利可圖,等待 |
| 15 ~ 20 | 低波動 | IVR 普偏低,賣方溢價不足 |
| 20 ~ 25 | 中性 | 正常市場,看個股機會 |
| 25 ~ 30 | 波動上升 | 賣 PUT 開始有溢價 |
| 30 ~ 40 | 恐慌 | 賣 PUT 高溢價時機(接近底部反彈) |
| > 40 | 極端恐慌 | 等止跌訊號,別接刀 |

## brief 設計原則(從這份哲學推出)

1. **三維檢視**:每份 brief 都要問三件事
   - 哪些優質股快到接貨區?(Sell PUT)
   - 哪些持倉到我的出場區?(Sell CALL)
   - 哪些優質股到深度便宜區?(LEAPS 進場)

2. **「離條件還多遠」優於「分數」**
   - ❌ 「NVDA leaps_entry 65/70 [white]」
   - ✅ 「NVDA 距 52W 高 -8.2%(需 ≥-15%,還差 6.8%)」

3. **結論導向**:每段最後寫「→ 結論:今日無 / 等 X」
   - 不要只丟數據,要告訴自己「現在該幹嘛 / 等什麼」

4. **跳過無關段落**
   - mode_3(不填部位)→ Sell CALL 段顯示「未啟用部位管理,跳過」
   - 沒 universe 內事件 → 「無」一個字就好,別硬補

5. **不用 trader 行話**
   - ❌ delta、theta、收 premium 比例、rolling 機制
   - ✅ 接貨區、出場區、白菜價、等待費
